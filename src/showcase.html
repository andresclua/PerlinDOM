    How to submit

    "Submit yours" opens src/showcase.json in GitHub's editor. Add an entry at the end of the list and propose the change; GitHub opens a pull request for you.

    {
  "title": "My project",
  "url": "https://example.com",
  "by": "Your name",
  "description": "One sentence, up to 220 characters.",
  "image": "showcase/my-project.jpg"
}

    The screenshot is optional but recommended: a 16:9 image (about 1200×675, under 300 KB, .jpg, .png or .webp) uploaded to src/public/showcase/ in the same pull request. Use GitHub's Add file → Upload files in that folder, then reference it as above.

    Links must be https. Entries are reviewed before they appear.
